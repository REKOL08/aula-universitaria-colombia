# Agente coordinador · Aula abierta

Responsabilidad: mantener el portal, enlaces entre proyectos, accesibilidad y documentación de coordinación. El portal debe seguir siendo estático, sin dependencias remotas ni compilación.

Decisión vigente (30 de octubre de 2026): conservar este trabajo documentado en GitHub y separado de ALLSoft. No integrar enlaces, código ni documentos en ALLSoft. No ampliar esta iniciativa sin nueva solicitud del propietario. Conservar las publicaciones de Pages existentes salvo instrucción explícita de retirarlas.

Los agentes especialistas trabajan en repositorios hermanos, cada uno con su propio AGENTS.md. No modificar sus carpetas sin encargo explícito. No introducir claves de API en frontend ni simular consultas de IA. No afirmar validación universal. Conservar cobertura y límites visibles.

Antes de publicar, revisar enlaces relativos y destinos de las tres herramientas, comprobar presentación móvil/escritorio, navegación con teclado y estado HTTP público. Actualizar documentación si cambia el alcance. Los agentes se ejecutan durante sesiones de desarrollo, no dentro de Pages.
